---
name: Gratis arrangementsreservasjon
description: Brukerens regler for gratis arrangementer og gratis medlemspris.
---

Når ordinærpris er 0 og ingen andre alternative priser eksisterer, skal reservasjon være åpen uten betalingskrav.

**Why:** Brukeren presiserte denne regelen.

**How to apply:** Skill slike gratis arrangementer fra arrangementer med ordinærpris eller alternative priser.

Verifiserte medlemmer med medlemspris 0 skal kunne melde seg på direkte uten betaling, selv om ordinærprisen er større enn 0.

**Why:** Brukeren valgte gratis direktepåmelding for verifiserte medlemmer.

**How to apply:** Bekreft medlemskap og gjeldende pris på serveren for riktig firma og arrangement. Ikke krev betalings- eller nullbeløpsflyt for dette gratis medlemsvalget; andre med pris større enn 0 må betale.
